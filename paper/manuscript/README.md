Target: Nature Sustainability, Article. Updated: 2 October 2026.

This is an editable, partial manuscript using the standard LaTeX `article` class.
It includes the working title, a six-paragraph Introduction, the existing Results
and Methods prose, ten cited references, and all four current main figures with

## Open in Overleaf

1. Create a new Overleaf project using **Upload Project** and select `bace_overleaf.zip`.
2. Select `main.tex` as the main document and **pdfLaTeX** as the compiler.
3. Use TeX Live 2025 if a version needs to be selected; the local build used that version.
4. Recompile. Overleaf runs the necessary LaTeX and BibTeX passes automatically.

The archive contains sources at its root and uses standard TeX packages. It has
no dependency on the research repository, absolute workspace paths, external
data files, Python, network access or shell escape for LaTeX compilation.
This package was prepared locally; it has not been uploaded to an Overleaf account.

## Local build

With Python 3 and an existing LaTeX installation, run this command from this folder:

```bash
python3 build.py
```

The helper runs `latexmk`, checks the final log, and writes `main.pdf` and
`bace_overleaf.zip`. It never regenerates manuscript text from Markdown.
For a direct compile without packaging:

```bash
latexmk -pdf -interaction=nonstopmode -halt-on-error -file-line-error -outdir=build main.tex
```

## Journal stage

The official Nature Sustainability pages were rechecked on 1 October 2026:

- [Initial formatting](https://www.nature.com/natsustain/submission-guidelines/initial-formatting) accepts PDF, Word or TeX/LaTeX; LaTeX submissions need compiled PDFs and initial visual formatting is flexible.
- [Final formatting](https://www.nature.com/natsustain/submission-guidelines/aip-and-formatting) requires editable text, permits standard LaTeX classes and requests a single text file with the reference list embedded from the `.bbl` at final submission.

Continue to use `references.bib` while writing. Prepare a separate final-submission
copy with the reference list embedded when that stage is reached. Retain the working
sources. A supplement, cover letter, source-data files and applicable reporting
materials must be prepared separately when their content is ready.

The current PDF is a working framework, not a completed submission.
