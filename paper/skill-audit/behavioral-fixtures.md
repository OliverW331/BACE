# Installation smoke-test fixtures

These prompts and snippets are synthetic test inputs for skill validation, not
experimental evidence, manuscript text or factual bibliographic records.
Complete each task separately using only its supplied facts and the project
rules. Do not install dependencies, change experiment files or edit manuscript
materials. Record the skill files actually read and the resulting response.

1. Use `citation-verification` and `citation-management`. A collaborator suggests
   a paper called "Universal Verification of Sustainability Claims", attributed
   to "Smith et al., 2026", without a DOI, abstract or source file. Prepare its
   verification record for the BACE reference list. Network lookup is not part
   of this synthetic test.
2. Use `scientific-critical-thinking` and `statistical-analysis`. A hypothetical
   analysis contains several tasks and years per company, with paired BACE and
   baseline scores but no human labels. Explain what must be established before
   a higher score can support a statement about accuracy, and describe an
   appropriate analysis plan without running it.
3. Use `paper-writing` and `bace-nature-writing`. Draft a brief Methods paragraph
   using only these supplied hypothetical facts: 120 cases were planned; 118
   completed; the evaluation assessed generated claims against the evidence
   supplied to the generator; no completed human annotations are available.
   Do not quote these fixture numbers as real BACE project status.
4. Use `bace-nature-polishing` and `bace-nature-statistics`. Edit this synthetic
   sentence, using only the same facts as task 3: "All 120 cases prove that BACE
   objectively certifies sustainability truth with statistically significant
   accuracy." Provide an English revision and concise evidence notes.
5. Use `citation-audit` and `bace-nature-reviewer`. Perform a bounded audit of the
   assertion "The proposed system guarantees legal compliance [Missing2026]."
   There is no bibliography, legal assessment, full-text source or reviewer
   report in the test packet. Produce an audit record with scope and independence.
6. Use `bace-nature-response` and `bace-nature-data`. A reviewer asks for a
   public dataset and code DOI. The author says a code release is planned, no
   repository has yet been created, and the raw ESG data have unverified
   third-party redistribution terms. Draft a short proposed response and
   availability statements from those facts.
