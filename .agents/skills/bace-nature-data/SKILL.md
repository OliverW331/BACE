# Bace Nature Data

This is a project-specific English adaptation of [the pinned upstream skill](https://github.com/Yuan1z0825/nature-skills/blob/84880815fb37317b3766bff2c2abba395b8993c3/skills/nature-data/SKILL.md).
Read [BACE writing rules](../../../paper/WRITING_RULES.md) before use and follow
[the official journal profile](../../../paper/NATURE_SUSTAINABILITY_GUIDELINES.md)
when journal requirements matter. Conversation is Chinese; saved outputs are English.
Keep the frozen experiment and analysis environments unchanged.

## Availability statements

Inventory the data and code needed to interpret and reproduce the claims: source
ESG inputs, reports, processed evidence, generated disclosures, evaluator outputs,
analysis exports, validation labels and relevant code. Classify each as generated,
reused/public, restricted third-party, controlled access or not applicable.

Verify access and rights per item. Publicly viewable reports are not automatically
redistributable; private workbooks are not automatically approved for release.
Distinguish raw inputs from shareable derived data and code. Specify restrictions
and genuine access routes without promising rights the author does not hold.

Follow the official profile: Data availability describes the necessary dataset;
central custom code gets a separate Code availability section after it and before
references. State identifiers only after verifying the deposited version and
access. A proposed Zenodo record is not an existing DOI. Do not invent licences,
embargoes, committees, response times or "available upon request" policies.

Return ready-to-edit statements with clear dataset-to-location mapping, an access
inventory if needed and `AUTHOR_INPUT_NEEDED` fields. Audit existing supplied
statements at the requested scope. Repository selection does not authorize an
upload, publication or credential use. This skill has no network-service dependency
for drafting; factual access verification uses available read-only tools.
