## Limits and follow-up polish

- The full inventory can be visually dense; the explicit Related only control and example shortcuts support focused review. This has not been evaluated with participants.
- Only one real case is allowlisted. Other case shapes, much larger inventories, and a dedicated mobile review workflow need separate validation.
- Exact source spans can overlap; a passage chooser prevents arbitrary DC selection. Ambiguous or unverifiable spans are marked unlocated. No approximate text matching is used.
- Standard keyboard controls, focus indicators, native dialog focus management, accessible labels, Escape, and reduced-motion CSS are present. Screen-reader usability, high text scaling, and a complete contrast audit remain outside this QA scope.
- The bottom diagnosis inspector remains the current design proposal, available for author feedback.
